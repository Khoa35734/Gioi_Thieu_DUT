# Hướng dẫn thêm Logo trường

## Vị trí file logo
Đặt file logo tại: `E:\Gioi_Thieu_DUT\src\main\webapp\assets\img\logo-dut.png`

## Yêu cầu kỹ thuật
- **Tên file:** logo-dut.png
- **Định dạng:** PNG (nền trong suốt) hoặc JPG
- **Kích thước đề xuất:** 200x200px hoặc tương đương (tỷ lệ 1:1)
- **Dung lượng:** < 100KB

## Logo Đại học Bách Khoa - Đại học Đà Nẵng
Bạn có thể tải logo chính thức từ:
- Website: https://dut.udn.vn
- Hoặc liên hệ phòng truyền thông của trường
